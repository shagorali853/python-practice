## 📚 Roadmap Overview

|    Part   | Topic                | Main Focus                                                        |
| :-------: | -------------------- | ----------------------------------------------------------------- |
| 🟢 **01** | Python Basics        | Syntax, variables, data types, operators, conditions & loops      |
| 🔵 **02** | Data Structures      | List, Tuple, Dictionary, Set, String, Comprehensions              |
| 🟣 **03** | `collections` Module | Counter, defaultdict, deque, namedtuple & advanced collections    |
| 🟠 **04** | Functions            | `*args`, `**kwargs`, lambda, recursion, decorators & generators   |
| 🔴 **05** | Python Handling      | Exceptions, Files, CSV, JSON, REST APIs                           |
| 🟡 **06** | OOP                  | Classes, inheritance, polymorphism, abstraction & design patterns |
| 🟦 **07** | Advanced Python      | Modules, concurrency, asyncio, memory & advanced techniques       |
| 🟢 **08** | Projects             | 25 practical projects from beginner to industry level             |
